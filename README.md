# CaptionIt

A tiny site that writes captions for your photos.

## What it does

- **AI captions:** upload a photo and CaptionIt writes an AI caption describing it.
- **Simple flow:** choose a photo, press the button and the caption appears under the photo.
- **Photo picker:** the try page lets you choose a photo and has a Write my caption button.
- **About page:** the About page explains what CaptionIt is.
- **Easy navigation:** the landing page links to the try page.

## Run the tests

```
npm test
```

## Deploy

Static pages in `public/` and one small serverless function in `api/`. It deploys to Vercel with no build step.
